# シニアのAI時代の生き方 — 自治会向け

ご近所・自治会向けに「AIを暮らしに安全に役立てるヒント」をやさしく紹介する、無料の静的HTMLサイトです。

## 内容
- A4縦の説明画像10枚を使った10章
- 文字の大きさ：小・中・大・特大
- 章の切替、拡大表示、質問例コピー、印刷
- ChatGPTのAndroid/iPhone公式インストールリンクと、声での入力・音声会話の案内
- 防災、詐欺対策、健康などのAI利用上の注意

## 公開サイト
GitHub Pagesで公開中です（配信反映には時間差が生じる場合があります）。

https://layetylor-efc.github.io/silverai/

## 編集
`index.html` がサイト本体です。10章の画像と既存のスタイル・JavaScriptはHTML内に埋め込まれ、v1.1の追加部分は `v11.css` と `v11.js` に分離しています。別の画像ホスティングやAPIキーは必要ありません。
