# シニアのAI時代の生き方 — 自治会向け

ご近所・自治会向けに「AIを暮らしに安全に役立てるヒント」をやさしく紹介する、無料の静的HTMLサイトです。

## 内容
- A4縦の説明画像10枚を使った10章
- 文字の大きさ：小・中・大・特大
- 章の切替、拡大表示、質問例コピー、印刷
- ChatGPTのAndroid/iPhone公式インストールリンクと、声での入力・音声会話の案内
- 防災、詐欺対策、健康などのAI利用上の注意

## 公開サイト
GitHub Pagesの設定が完了すると、以下で閲覧できます。

https://layetylor-efc.github.io/silverai/

## GitHub Pagesの設定
リポジトリ **Settings → Pages → Build and deployment** にて **Deploy from a branch** を選び、 **Branch: main / /(root)** を設定し保存してください。設定後、公開ページの動作を確認してください。

## 編集
`index.html` がサイト本体です。画像・スタイル・JavaScriptはHTML内に埋め込んであり、別の画像ホスティングやAPIキーは必要ありません。
